I'm an **Infrastructure Engineer** working at an IT services company, with experience across on-premises, cloud, and hybrid IT environments.

My professional experience covers infrastructure administration, virtualization, Microsoft technologies, identity and access management, endpoint management, cybersecurity, backup and recovery, and infrastructure monitoring.
